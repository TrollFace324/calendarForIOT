# Планировщик расписания ИРИТ

Локальное приложение собирает варианты расписания из доступных групп. У каждой дисциплины выбирается одна группа. Группа может включать несколько еженедельных занятий.

## Запуск

Нужен .NET 9 SDK. В папке проекта выполните `dotnet run` и откройте адрес из вывода команды. При ограниченном доступе к пользовательскому NuGet.Config сначала выполните:

```powershell
$env:APPDATA = (Get-Location).Path
dotnet restore --configfile NuGet.Config
dotnet run --no-restore
```

На странице есть пример с желанным преподавателем, ведущим занятие в субботу. Данные можно менять в форме, сохранять в JSON и загружать обратно. Изменения автоматически сохраняются в браузере.

## Данные Modeus

Кнопка «Импорт групп из HAR» читает ответы `student-campaign-menu` и `module-elements` из архива Firefox. Она заполняет модули, циклы, группы и преподавателей. Затем кнопка «Импорт времени из HAR» сопоставляет события календаря с группами по ID дисциплины и названию группы. Оба архива обрабатываются в браузере, а в локальном хранилище остаются только извлечённые варианты. Группы без времени автоматически пропускаются при расчёте.

Календарный архив может содержать события только за один день или короткий период. Импортированное время временно считается еженедельным. Такие группы помечены напоминанием проверить повторяемость и при необходимости указать `ч` или `з` в поле занятий.

Раздел «Расписание из Modeus» принимает полный JSON-ответ поиска событий календаря Modeus (`/schedule-calendar-v2/api/calendar/events/search`). Он показывает уже назначенные занятия в екатеринбургском времени. Формат ответа и поле `_embedded.events` сверены с [реализацией клиента расписания УрФУ](https://github.com/be1pheg0r/urfu-mcp/blob/main/urfu_mcp/modeus/normalizer.py).

Для полного расписания всех вариантов нужно открыть соответствующие группы в календаре Modeus и импортировать ответы с их событиями.

## Правила подбора

- Планировщик выбирает по одной группе для каждой дисциплины и исключает сочетания с пересечениями по времени.
- Закреплённая группа обязательна для своей дисциплины. Недоступные группы исключаются.
- Варианты сравниваются строго в заданном пользователем порядке. Оценка преподавателей складывается по выбранным группам. Далее учитываются число субботних занятий, суммарная длительность окон и число учебных дней за две недели.
- Показываются десять лучших вариантов. При поиске более 500 000 допустимых сочетаний появляется предупреждение о неполном результате.
- Окно считается между соседними занятиями одного дня. Обычный перерыв между парами тоже входит в это время.

## Границы первой версии

Встречи можно указать для каждой недели, только числителя (`ч`) или только знаменателя (`з`). Полусеместры и вместимость групп пока не учитываются.
