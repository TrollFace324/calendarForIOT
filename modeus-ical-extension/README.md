# Пара.План — экспорт Modeus

Расширение для Chrome читает карточки занятий в календаре Modeus УрФУ и создаёт один файл .ics на дисциплину. Можно экспортировать одну дисциплину или целое меню выбора. Сервер и пароль расширению не нужны. Сайт schedule-studio работает отдельно.

## Установка

1. Откройте chrome://extensions и включите **Режим разработчика**.
2. Нажмите **Загрузить распакованное расширение** и выберите папку modeus-ical-extension, в которой лежит manifest.json.
3. При желании закрепите «Пара.План — экспорт Modeus» через меню расширений Chrome.

Если расширение уже установлено, нажмите **Обновить** на его карточке в chrome://extensions, затем обновите страницу Modeus.

## Экспорт всех дисциплин

1. В Modeus откройте **Выбор модулей** и нужное меню семестра. Оставьте поиск пустым и выключите «Выбранные» и «Избранные», чтобы обработать все варианты.
2. Нажмите значок расширения → **Открыть массовый сборщик**. Проверьте дату начала, нажмите **Выбрать дисциплины**, затем **Собрать выбранные**. По умолчанию отмечено всё меню. Чтобы не скачивать готовые файлы повторно, нажмите **Снять все** и отметьте только нужные дисциплины. При повторе с теми же датами в открытой панели автоматически отмечаются незавершённые дисциплины последнего запуска.
3. Оставьте обе вкладки открытыми. Сборщик по очереди загружает календари дисциплин в отдельную вкладку и читает карточки занятий. Чтобы остановить сбор, вернитесь на вкладку меню и нажмите **Остановить**.
4. Chrome сохраняет файлы в **Загрузки → название меню выбора [ID] → раздел → дисциплина.ics**. У каждой кампании своя папка прямо в «Загрузках», без общей папки Modeus и вложенной папки запуска. Короткий ID различает одноимённые кампании. При повторном скачивании Chrome добавляет номер к имени файла, не перезаписывая существующий. Если Chrome спрашивает, куда сохранить файлы, подтвердите предложенные пути или выключите этот запрос в настройках загрузок.

Если за выбранные даты занятий нет, пустой файл не создаётся. Список таких дисциплин, завершённых выгрузок и ошибок виден в панели. Сбор ограничен одним меню за запуск.

При ошибке сборщик делает до трёх попыток на дисциплину. Если остаются недостающие файлы, кнопка **Повторить попытку** проверяет только их и дополняет ту же папку кампании. Уже сохранённые файлы и дисциплины без занятий повторно не собираются. Кнопка доступна, пока панель открыта; если Modeus запросил вход, сначала войдите в отдельной вкладке.

## Границы сбора

В массовом сборщике поле **От** заполняется датой начала выбора, если она указана, или датой из ссылки «Расписание выбранных команд». Без этих данных подставляется начало семестра, как при сборе из календаря. Дату можно изменить. Если поле **До** пустое, сбор идёт вперёд и заканчивается после двух подтверждённых пустых месяцев подряд после занятий. Новый месяц с занятиями сбрасывает счётчик пустых. Ошибка выгрузки не считается пустым месяцем.

Чтобы не пропустить поздний старт, до первой пары проверяется до пяти месяцев. Если за это время занятий нет, файл не создаётся. Для дисциплин с занятиями есть защитный предел в 12 месяцев; если к этому моменту конец не найден, сборщик сообщает об этом. Для выгрузки конкретного интервала укажите дату **До** вручную: обе даты включены, правило двух пустых месяцев не применяется.

## Экспорт одной дисциплины

1. Войдите в Modeus УрФУ, откройте **Мое расписание → Фильтры** и оставьте одну нужную дисциплину. Если нужны все подгруппы, не ограничивайте фильтр отдельной подгруппой или участником.
2. На этой вкладке нажмите значок расширения → **Открыть сборщик**.
3. Проверьте дату начала, оставьте **До** пустым для автоматического окончания и нажмите **Собрать .ics**.
4. Оставьте вкладку открытой и не меняйте на ней фильтры или даты. Расширение пролистает календарь только по месяцам. Занятия за пределами выбранного периода не добавляются.
5. В конце файл .ics сохранится в папке **Расписание Modeus — дата и время запуска** прямо в «Загрузках». Если Chrome не начал загрузку, нажмите **Сохранить ещё раз**: файл попадёт в ту же папку. Файл можно загрузить в Пара.План через **Импорт ICS**.

Если остановить сбор или он прервётся с ошибкой, уже полученные занятия можно скачать кнопкой **Скачать собранное**, пока панель открыта. Если Modeus перенаправил на страницу входа, войдите снова и повторите сбор.

Оба вида сбора используют месячный календарь. Сборщик пропускает месяцы без занятий. Если карточки месяца не удалось прочитать, сбор этой дисциплины останавливается с объяснением. При массовом сборе обработка остальных дисциплин продолжается.

Панель показывает ход сбора от 0 до 100%. Если дата окончания определяется автоматически, процент во время работы приблизительный. При остановке шкала сохраняет достигнутое значение.

В конце панель показывает итог сбора. Кнопка **Показать папку** открывает файловый менеджер с сохранённым .ics. При массовом сборе открывается раздел с одним из сохранённых файлов.

В файл попадают даты и время, названия занятий, подгруппы, аудитории или ссылки и преподаватели из карточек. Если в названии команды есть пометка «ведет …» или «ведёт …», она добавляется к имени преподавателя в скобках. Дубликаты удаляются по идентификатору занятия. Обработка выполняется в браузере.

Если у занятий одной дисциплины совпадает пометка о ведущем и у неё есть однозначное ФИО преподавателя, это имя подставляется вместо технической записи `support`.

Если у одной команды есть несколько преподавателей для одного вида занятий, в строке «Преподаватель» записываются все их ФИО через «и».
